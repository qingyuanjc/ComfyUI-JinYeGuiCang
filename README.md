# 🍂 叶落归仓 (JinYeGuiCang)

一个给 ComfyUI 用的**极轻量显存 / 内存清理节点**。

把它插在工作流的任意连线上，数据原样穿过（图进图出、latent 进 latent 出），它只在背后顺手把 ComfyUI 占着的显存 / 内存清掉。适合跑完一个重任务（比如长视频生成）后，自动腾空显存给下一个任务。

## 特点

- **万能口直通**：输入什么类型就输出什么类型，不改变数据，接线位置随意。
- **三个开关各自独立**：卸载模型 / 回收内存 / 清显存缓存，想开哪个开哪个。
- **间隔计数**：可选「每跑 N 次清一次」，0 表示每次都清。计数存在内存里，重启归零。
- **零依赖**：不用装任何第三方库，只用 ComfyUI 自带模块。
- **全异常兜底**：任何情况下都不会报错中断你的工作流，最坏只是这一次没清成。
- **全关 = 透明**：三个开关全关时，节点等于一根直连线，不会误清别人的模型。

## 安装

1. 把本文件夹放到 `ComfyUI/custom_nodes/` 下：

   ```
   ComfyUI/custom_nodes/ComfyUI-JinYeGuiCang/
   ```

2. **重启 ComfyUI**。

3. 在画布空白处双击，搜索 `叶落归仓` 或 `JinYeGuiCang` 即可找到节点。

不需要 pip 安装任何依赖，也不需要 ComfyUI-Manager。

## 用法

拖出节点后，把你要穿过的那根线（图片 / 视频 / latent 都行）从原来直连的地方改接到节点的 `anything` 输入口，再从 `output` 输出口接回去。

四个参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `间隔（0=每次清）` | 每运行 N 次才清理一次；0 = 每次都清 | 0 |
| `卸载模型` | 让 ComfyUI 在本次执行结束后卸载模型 | 开 |
| `回收内存` | 让 ComfyUI 在本次执行结束后回收内存 | 开 |
| `清显存缓存` | 立即调用 `soft_empty_cache()` 清显存缓存（安全、不卸载模型） | 开 |

三个开关显示为「开 / 关」，点一下即可切换。

## 它清的是什么

- 能清：ComfyUI 加载的模型权重，以及它自己的缓存。
- 清不掉：显卡驱动和系统常驻保留的显存（约 1GB 上下）——这是任何工具都清不掉的正常现象，并不是没清干净。

## 兼容性

- 无需 ComfyUI-Manager。
- 前端外观层（`web/`）只做美化，任何异常都会静默降级为原生外观，不影响节点功能。
- Python 侧对 `PromptServer`、`comfy.model_management` 的调用均有异常保护，独立导入也不会崩。
